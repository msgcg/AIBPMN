# BPMN-as-Code: Базовый синтаксис и структура процесса

Каждая диаграмма описывается на декларативном языке BPMN-as-Code (DSL).
Каждый процесс ДОЛЖЕН начинаться с объявления имени:
```
process "Название бизнес-процесса"
```

## Правила синтаксиса
1. Идентификаторы узлов (ID) пишутся на латинице в формате snake_case (например: `order_received`, `check_inventory`, `manager_approval`). ID обязаны быть уникальными.
2. Лейблы узлов заключаются в двойные кавычки (например: `"Заказ получен"`, `"Проверить остатки на складе"`).
3. Лейблы задач должны быть глагольными формами: «Проверить данные», «Сформировать счет», «Отправить уведомление».
4. Комментарии начинаются с символа `#` и могут располагаться на отдельной строке или в конце строки.
5. Узлы объявляются через ключевые слова с двоеточием: `start:`, `end:`, `task:`, `gateway:`, `subprocess:`, `call:`, `note:`, `data:`, `datastore:`.
6. После объявления узлов объявляются связи (flows) через стрелки `->`.
