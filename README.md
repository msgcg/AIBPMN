> [!IMPORTANT]
> ## Инструкция: быстрый запуск за 5 минут (с получением ключа Сбера) ниже:

### Шаг 1. Получите бесплатный ключ Сбер GigaChat API (2 минуты)

Для проектирования процессов ИИ-архитектору нужен доступ к нейросети **Сбер GigaChat**. Для физических лиц Сбер даёт **1 000 000 бесплатных токенов каждый месяц** (этого хватит на сотни бизнес-схем):

1. Перейдите на портал разработчиков: [**developers.sber.ru/studio**](https://developers.sber.ru/studio) (или [developers.sber.ru](https://developers.sber.ru/)).
2. Нажмите кнопку **«Войти»** в правом верхнем углу и авторизуйтесь через **Сбер ID** (по номеру телефона, доступно всем).
3. Перейдите в раздел **«Кабинет»** $\rightarrow$ вкладка **«GigaChat API»**.
4. Нажмите зелёную кнопку **«Создать проект»**:
   - Выберите тип проекта: **«Для физических лиц»** (бесплатный тариф).
   - Введите любое имя проекта (например, `AIBPMN`) и нажмите **«Создать»**.
5. В созданном проекте найдите поле **«Авторизационные данные»** (это длинная строка из букв, цифр и знаков `=`, например `MDE5M2Zh...`).
6. Нажмите иконку **«Копировать»** рядом с этим полем. Этот ключ нам понадобится на Шаге 2!

> [!NOTE]
> Нужна именно строка **«Авторизационные данные»** (Base64-ключ). Отдельные Client ID и Client Secret копировать не требуется.

### Шаг 2. Запуск приложения на компьютере (3 минуты)

Убедитесь, что на компьютере установлен **Python 3.10+** ([скачать с python.org](https://www.python.org/downloads/)) и **Git** ([скачать с git-scm.com](https://git-scm.com/)). При установке Python обязательно поставьте галочку **«Add python.exe to PATH»**.

#### Вариант для Windows:

1. Откройте меню «Пуск», введите **PowerShell** (или «Терминал») и запустите его.
2. Перейдите в папку проекта (или скачайте репозиторий):

   ```powershell
   git clone https://github.com/msgcg/AIBPMN.git
   cd AIBPMN
   ```
3. Создайте и включите изолированное виртуальное окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   *(Если появится красная ошибка о запрете выполнения скриптов, выполните команду: `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` и повторите активацию).*
4. Установите библиотеки проекта:

   ```powershell
   pip install -r requirements.txt
   ```
5. Создайте файл настроек `.env` из готового шаблона:

   ```powershell
   Copy-Item .env.example .env
   ```
6. Откройте созданный файл `.env` в Блокноте:

   ```powershell
   notepad .env
   ```

   Найдите строку:
   ```dotenv
   GIGACHAT_AUTH_KEY=your_gigachat_auth_key_here
   ```

   Вместо `your_gigachat_auth_key_here` вставьте ваш скопированный ключ из Шага 1. Сохраните файл (`Ctrl + S`) и закройте Блокнот.
7. Инициализируйте базу данных (создастся локальный файл `db.sqlite3`):

   ```powershell
   python manage.py migrate
   ```
8. Запустите сервер:

   ```powershell
   python manage.py runserver
   ```

#### Вариант для Linux / macOS:

```bash
# 1. Скачивание и переход в папку

# 4. Настройка файла .env
cp .env.example .env
# Откройте .env в любом редакторе и вставьте ваш ключ в GIGACHAT_AUTH_KEY=...
nano .env

# 5. База данных и запуск
python manage.py migrate
python manage.py runserver
```

## ◆ О проекте

**AIBPMN** объединяет декларативный подход «диаграмма как код» (*Diagrams as Code*) с возможностями современных нейросетевых моделей (LLM API). Вместо ручного перетаскивания и соединения сотен блоков мышью аналитик или разработчик описывает бизнес-логику на обычном естественном языке в интерактивном чате с ИИ-архитектором либо сам программирует схему на простом языке **BPMN-as-Code (DSL)**.

Система автоматически:

1. Анализирует бизнес-требования с учётом загруженных корпоративных регламентов и документации (RAG-контекст).
2. Генерирует синтаксически корректный код процесса.
3. Компилирует его в валидную схему стандарта **BPMN 2.0**.
4. Мгновенно визуализирует интерактивный граф на холсте с автоматической расстановкой узлов.
5. Позволяет редактировать диаграмму в чате, коде, и в визуальном редакторе - изменения подхватываются системой автоматически.

## ✦ Ключевые возможности

### ▸ Интеллектуальный архитектор (GigaChat AI)

- **Генерация с нуля**: проектирование структуры процессов по текстовому описанию на естественном языке.
- **Интерактивная доработка диалога**: добавление веток, шлюзов, ролей, таймеров, обработчиков ошибок без потери контекста.
- **RAG-поддержка (Retrieval-Augmented Generation)**: контекст генерации автоматически обогащается нормативными регламентами и правилами из персональной базы знаний пользователя.
- **Автоматическая коррекция синтаксиса**: проверка валидности генерируемого кода, парности шлюзов и достижимости узлов.

### ▸ Текстовый редактор BPMN-as-Code (DSL)

- Декларативный синтаксис, максимально удобный для аналитиков, разработчиков и языковых моделей.
- Полноэкранный режим работы с кодом с быстрым возвратом (`Esc` на клавиатуре или кнопка «Свернуть»).
- Высококонтрастная подсветка синтаксиса для тёмной и светлой тем оформления (на базе расширенной грамматики Prism.js).
- Встроенная интерактивная справка по синтаксису прямо в IDE с готовыми примерами и вставкой в редактор в один клик.

### ▸ Визуальный интерактивный редактор (BPMN 2.0 Canvas)

- Полнофункциональный рендеринг на базе открытого движка `bpmn-js`.
- Полноценная поддержка сенсорных экранов и мобильных устройств (плавное панорамирование холста одним пальцем, зум двумя пальцами *Pinch-to-Zoom*, перетаскивание фигур).
- Экспорт диаграммы в форматы `.bac` (исходный код DSL), `.png` (растровый), `.pdf` (документ) и `.svg` (векторный).

### ▸ Мультипроектность и управление историей

- Создание, переименование и переключение между проектами и диаграммами.
- Полное сохранение истории диалога с ИИ и состояний диаграммы.
- Индивидуальное или пакетное удаление сообщений чата.

### ▸ Персональная база знаний

- Изолированное хранилище документов для каждого зарегистрированного пользователя.
- Хранение файлов в базе данных в формате Base64 (не зависит от файловой системы сервера).
- Защита от загрузки небезопасных или бинарных файлов (фильтрация по черному списку опасных расширений и лимиту размера).
- Декодирование файлов неизвестных, но технически поддерживаемых форматов.
- Скачивание файлов из базы знаний в исходном виде.

### ▸ Безопасность и профили пользователей

- Регистрация и аутентификация с проверкой логина и надежности пароля (проверка в реальном времени: заглавные/строчные буквы, цифры, спецсимволы, длина от 8 символов, и тп.).
- Возможность ознакомительного гостевого режима (Guest mode).
- Настройки профиля: смена пароля и полное удаление аккаунта с каскадной очисткой всех связанных проектов, диаграмм и файлов.
- Раздельные профили конфигурации для локальной разработки (`dev.py`) и промышленной эксплуатации (`prod.py`).

### ▸ Progressive Web App (PWA) и поддержка всех платформ

- Установка приложения в виде нативного окна на Android, iOS (Safari "На экран Домой"), Windows (Edge/Chrome), macOS и Linux.
- Фирменный комплект векторных и растровых иконок (16x16, 32x32, 180x180, 192x192, 512x512, maskable) и `favicon.ico`.
- Безопасный Service Worker: строгое кеширование только статики, исключающее вмешательство в навигацию и API-запросы для сохранения 100% стабильности CSRF-авторизации Django.

### ▸ Панель администратора и автогенерация SEO

- Полнофункциональная административная панель Django (`/admin/`) с преднастроенным рут-пользователем `max` (`Admin2026!Bpmn`).
- Наглядные интерфейсы со счетчиками диаграмм, подсветкой ролей в чате, предпросмотром XML и декодированием Base64 базы знаний.
- Динамическая генерация `robots.txt` и `sitemap.xml` по стандартам поисковых систем, а также консольная команда `python manage.py generate_seo`.

## ≡ Спецификация языка BPMN-as-Code

Язык **BPMN-as-Code (BAC)** — это минималистичный декларативный синтаксис, ориентированный на быстрое и однозначное описание бизнес-процессов.

### Пример процесса обработки онлайн-заказа:

```bac
process "Обработка заказа в интернет-магазине"

# События
start: order_received "Заказ поступил"
end: order_completed "Заказ успешно доставлен"

# Задачи и исполнители (Swimlanes)
service: check_stock "Проверить наличие товаров на складе"
user: pack_order "Собрать и упаковать заказ" by "Склад"
service: charge_payment "Списать оплату с карты" by "Биллинг"
user: deliver_order "Доставить заказ клиенту" by "Курьерская служба"

# Шлюзы
gateway: exclusive is_available "Все позиции в наличии?"
end: order_cancelled "Заказ отменен (нет на складе)"

# Связи процесса и условные ветвления
order_received -> check_stock
check_stock -> is_available

# Условные переходы
is_available --[Да]--> pack_order
is_available --[Нет]--> order_cancelled

pack_order -> charge_payment
charge_payment -> deliver_order
deliver_order -> order_completed
```

### Основные конструкции языка:

- **Объявление процесса**: `process "Название процесса"` (первая строка).
- **События**:
  - `start: id "Имя"` — начальное событие.
  - `end: id "Имя"` — конечное событие.
  - `catch: id "Имя"` / `throw: id "Имя"` — промежуточные события.
- **Задачи**:
  - `user: id "Имя" [by "Роль"]` — пользовательская задача (User Task).
  - `service: id "Имя"` — системная задача / обращение к сервису (Service Task).
  - `script: id "Имя"` — скрипт / автоматическое вычисление (Script Task).
  - `manual: id "Имя"` — ручная физическая операция (Manual Task).
- **Шлюзы**:
  - `gateway: exclusive id "Вопрос?"` — исключающий шлюз (XOR).
  - `gateway: parallel id "Разветвление"` — параллельный шлюз (AND).
  - `gateway: inclusive id "Условия"` — включающий шлюз (OR).
- **Связи**:
  - `a -> b` — безусловный поток управления (Sequence Flow).
  - `gw --[Условие]--> target` — условный переход (Conditional Flow).
  - `gw ==> target` — переход по умолчанию (Default Flow).
- **Примечания**: `note: "Текст заметки" on node_id`.
